## 🎯 ১. শিক্ষাগত যোগ্যতা ও শর্তাবলি (Official Requirements)
1. কোনো স্বীকৃত বোর্ড হইতে **উচ্চ মাধ্যমিক সার্টিফিকেট (HSC)** বা সমমানের পরীক্ষায় উত্তীর্ণ।
2. কম্পিউটার মুদ্রাক্ষরে সর্বনিম্ন গতি:
   - **বাংলা:** প্রতি মিনিটে ২০ শব্দ
   - **ইংরেজি:** প্রতি মিনিটে ২০ শব্দ
3. সংশ্লিষ্ট বিষয়ে **Standard Aptitude Test (স্ট্যান্ডার্ড অ্যাপটিটিউড টেস্ট)**-এ উত্তীর্ণ হইতে হবে।
