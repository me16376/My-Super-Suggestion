## 📌 ১. একক লিংকড লিস্ট রিভার্স করার গোল্ডেন অ্যালগরিদম

একটি Singly Linked List-কে O(n) সময়ে এবং O(1) ইন-প্লেস মেমরিতে উল্টানোর জন্য ৩টি পয়েন্টার (`prev`, `curr`, `next`) ব্যবহৃত হয়:

```c
struct Node* reverseList(struct Node* head) {
    struct Node *prev = NULL;
    struct Node *curr = head;
    struct Node *next = NULL;
    
    while (curr != NULL) {
        next = curr->next; // পরবর্তী নোড সংরক্ষণ
        curr->next = prev; // পেছনের নোডে পয়েন্টার ঘুরিয়ে দেওয়া
        prev = curr;       // prev এক ধাপ সামনে নেওয়া
        curr = next;       // curr এক ধাপ সামনে নেওয়া
    }
    return prev; // নতুন হেড রিটার্ন
}
```

> [!TIP]
> পয়েন্টার ঘোরানোর ৪টি ধারাবাহিক লাইন মুখস্থ রাখার কৌশল:
> `next = curr->next` ➔ `curr->next = prev` ➔ `prev = curr` ➔ `curr = next`

## 📌 ২. ফ্লয়েডের সাইকেল ডিটেকশন (Floyd's Tortoise and Hare)

লিংকড লিস্টে কোনো ইনফাইনাইট লুপ বা সাইকেল আছে কিনা তা O(1) মেমরিতে শনাক্ত করার জন্য স্লো (১ ধাপ) ও ফাস্ট (২ ধাপ) পয়েন্টার ব্যবহৃত হয়:

```c
int hasCycle(struct Node* head) {
    struct Node *slow = head, *fast = head;
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;        // ১ ধাপ আগায়
        fast = fast->next->next;  // ২ ধাপ আগায়
        if (slow == fast) {
            return 1; // লুপ শনাক্ত হয়েছে!
        }
    }
    return 0; // কোনো লুপ নেই
}
```

## 📌 ৩. ইনফিক্স থেকে পোস্টফিক্স রূপান্তর (স্ট্যাক ট্রেস)

**এক্সপ্রেশন:** `A + B * (C - D) / E`

| ইনপুট টোকেন | স্ট্যাক (Stack) | পোস্টফিক্স আউটপুট | ব্যাখ্যা |
| :---: | :--- | :--- | :--- |
| **A** | [খালি] | `A` | অপারেন্ড সরাসরি আউটপুটে যায় |
| **+** | `+` | `A` | অপারেটর স্ট্যাকে পুশ হয় |
| **B** | `+` | `A B` | অপারেন্ড আউটপুটে যায় |
| ***** | `+ *` | `A B` | `*` এর অগ্রাধিকার `+` এর চেয়ে বেশি, পুশ হয় |
| **(** | `+ * (` | `A B` | বাম বন্ধনী স্ট্যাকে পুশ হয় |
| **C** | `+ * (` | `A B C` | অপারেন্ড আউটপুটে যায় |
| **-** | `+ * ( -` | `A B C` | `-` পুশ হয় |
| **D** | `+ * ( -` | `A B C D` | অপারেন্ড আউটপুটে যায় |
| **)** | `+ *` | `A B C D -` | ডান বন্ধনী আসায় `(` পর্যন্ত সমস্ত অপারেটর পপ হয় |
| **/** | `+ /` | `A B C D - *` | `/` এবং `*` এর অগ্রাধিকার সমান হওয়ায় পূর্বের `*` পপ হয়, তারপর `/` বসে |
| **E** | `+ /` | `A B C D - * E` | অপারেন্ড আউটপুটে যায় |
| **End** | [খালি] | `A B C D - * E / +` | স্ট্যাকের অবশিষ্ট সমস্ত অপারেটর (`/`, `+`) পপ হয় |

* **চূড়ান্ত পোস্টফিক্স রূপ:** `A B C D - * E / +`

## 📌 ৪. সার্কুলার কিউ (Circular Queue) ও বাউন্ডারি শর্তসমূহ

লিনিয়ার কিউ-তে সামনের জায়গা খালি থাকলেও পেছনের `rear` শেষে পৌঁছালে আর ডেটা ঢোকানো যায় না। এই মেমরি অপচয় দূর করতে সার্কুলার কিউ ব্যবহৃত হয়।

* **Queue Full শর্ত:** `(rear + 1) % MAX_SIZE == front`
* **Queue Empty শর্ত:** `front == -1`
* **Enqueue:** `rear = (rear + 1) % MAX_SIZE; arr[rear] = item;`
* **Dequeue:** `item = arr[front]; front = (front + 1) % MAX_SIZE;`

## 📌 ৫. বাইনারি সার্চ ট্রি (BST) ট্রাভার্সাল নিয়ম

যেকোনো BST-এর ৩টি ট্রাভার্সাল মনে রাখার সহজ উপায়:

```text
        50
       /  \
     30    70
    /  \  /  \
   20  40 60  80
```

1. **Inorder (Left ➔ Root ➔ Right):** `20, 30, 40, 50, 60, 70, 80`
   *(গোল্ডেন রুল: BST-এর Inorder ট্রাভার্সাল সর্বদা উপাদানগুলোকে ছোট থেকে বড় ক্রমে সাজিয়ে দেয়)।*
2. **Preorder (Root ➔ Left ➔ Right):** `50, 30, 20, 40, 70, 60, 80`
3. **Postorder (Left ➔ Right ➔ Root):** `20, 40, 30, 60, 80, 70, 50`

## 📌 ৬. সার্চিং ও সর্টিং অ্যালগরিদমের টাইম কমপ্লেক্সিটি সারসংক্ষেপ

| অ্যালগরিদম | Best Time | Average Time | Worst Time | Space Complexity | স্ট্যাবিলিটি |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Linear Search** | O(1) | O(n) | O(n) | O(1) | — |
| **Binary Search** | O(1) | O(log n) | O(log n) | O(1) | — |
| **Bubble Sort** | O(n) | O(n^2) | O(n^2) | O(1) | Stable |
| **Insertion Sort** | O(n) | O(n^2) | O(n^2) | O(1) | Stable |
| **Merge Sort** | O(n log n) | O(n log n) | O(n log n) | O(n) | Stable |
| **Quick Sort** | O(n log n) | O(n log n) | O(n^2) | O(log n) | Unstable |

> [!IMPORTANT]
> **কুইক সর্টের Worst-case O(n^2) পরিহারের উপায়:** অ্যারে আগে থেকে সাজানো থাকলে প্রথম উপাদান পিভট না নিয়ে **Randomized Pivot** অথবা **Median-of-three** পিভট নির্বাচন করতে হয়।
