# 🇧🇩 পেট্রোবাংলা উপ-সহকারী প্রকৌশলী (কম্পিউটার/আইটি) প্রস্তুতি
## ধাপ ১২: বাংলা ব্যাকরণ ও সাহিত্য প্রস্তুতি (Bangla Grammar & Literature Master Guide)

> **বুয়েট (BUET) ফোকাস বিশ্লেষণ:** বুয়েটের ওএমআর পরীক্ষায় বাংলা ভাষা ও ব্যাকরণ থেকে **১০ থেকে ১৫ নম্বর** থাকে। এর মধ্যে ব্যাকরণ অংশ (সন্ধি, সমাস, কারক, বাক্য শুদ্ধি, ণ-ত্ব/ষ-ত্ব বিধান ও প্রত্যয়) থেকে প্রায় ৭০-৮০% প্রশ্ন এবং শীর্ষ কবি-সাহিত্যিক ও প্রাচীন-মধ্যযুগ থেকে বাকি ২০-৩০% প্রশ্ন আসে। নিচে সর্বাধিক জিজ্ঞাসিত বিষয়সমূহ সুসংহত করা হলো।

## 📌 ১. নিপাতনে সিদ্ধ ও বিশেষ সন্ধিসমূহ (বুয়েটের সবচেয়ে প্রিয়)

নিয়ম বহির্ভূতভাবে যে সন্ধিগুলো সাধিত হয় সেগুলোকে **নিপাতনে সিদ্ধ সন্ধি** বলে:

| শব্দ | সঠিক সন্ধি বিচ্ছেদ | নিয়ম / প্রকার |
| :--- | :--- | :--- |
| **আশ্চর্য** | আ + চর্য | নিপাতনে সিদ্ধ ব্যঞ্জনসন্ধি |
| **একাদশ** | এক + দশ | নিপাতনে সিদ্ধ |
| **তস্কর** | তৎ + কর | নিপাতনে সিদ্ধ (অর্থ: চোর) |
| **বৃহস্পতি** | বৃহৎ + পতি | নিপাতনে সিদ্ধ |
| **বনস্পতি** | বন + পতি | নিপাতনে সিদ্ধ (যে গাছে ফুল ছাড়া ফল ধরে) |
| **মনীষা** | মনস্ + ঈষা | নিপাতনে সিদ্ধ ব্যঞ্জনসন্ধি |
| **পতঞ্জলি** | পতৎ + অঞ্জলি | নিপাতনে সিদ্ধ |
| **গবাক্ষ** | গো + অক্ষ | নিপাতনে সিদ্ধ স্বরসন্ধি (অর্থ: জানালা) |
| **অহর্নিশ** | অহঃ + নিশ (বা নিশা) | বিসর্গ সন্ধি |
| **শিরচ্ছেদ** | শিরঃ + ছেদ | বিসর্গ সন্ধি |
| **পুরস্কার** | পুরঃ + কার | বিসর্গ সন্ধি (দন্ত্য-স) |
| **পরিষ্কার** | পরি + কার | ষ-ত্ব বিধানজনিত (মূর্ধন্য-ষ) |

## 📌 ২. সমাস নির্ণয়ের সহজ টেকনিক

| সমাসের নাম | চেনার প্রধান উপায় ও অর্থ প্রাধান্য | উদাহরণ |
| :--- | :--- | :--- |
| **দ্বন্দ্ব সমাস** | উভয় পদের অর্থই প্রধান থাকে এবং মাঝে 'ও, এবং, আর' থাকে। | মাতা ও পিতা = মাতাপিতা, দোয়াত ও কলম = দোয়াত-কলম |
| **দ্বিগু সমাস** | পূর্বপদ সংখ্যাবাচক এবং সমস্তপদে সমাহার/সমষ্টি বোঝায়। (পরপদ প্রধান)। | তিন কালের সমাহার = ত্রিকাল, চৌরাস্তার সমাহার = চৌরাস্তা |
| **কর্মধারয় সমাস** | বিশেষণ + বিশেষ্য যোগে গঠিত হয় এবং পরপদের অর্থ প্রধান থাকে। | নীল যে পদ্ম = নীলপদ্ম, মহান যে নবী = মহানবী |
| **তৎপুরুষ সমাস** | পূর্বপদের বিভক্তি লোপ পায় এবং পরপদের অর্থ প্রধান থাকে। | বিপদকে আপন্ন = বিপদাপন্ন (২য়া), রথকে দেখা = রথদেখা |
| **বহুব্রীহি সমাস** | পূর্বপদ বা পরপদ কোনোটির অর্থ না বুঝিয়ে **সম্পূর্ণ নতুন ৩য় কোনো ব্যক্তি/বস্তু** বোঝায়। | দশ আনন যার = দশানন (রাবণ), পীত অম্বর যার = পীতাম্বর (শ্রীকৃষ্ণ), নদী মাতা যার = নদীমাতৃক |
| **অব্যয়ীভাব সমাস** | পূর্বপদে অব্যয় যুক্ত হয় এবং অব্যয়ের অর্থই প্রধান থাকে। | কূলের সমীপে = উপকূল, কণ্ঠের সমীপে = উপকণ্ঠ, মিলের অভাব = গরমিল |

## 📌 ৩. কারক ও বিভক্তি নির্ণয়ের কৌশল

| কারক | প্রশ্ন করার উপায় | উদাহরণ |
| :--- | :--- | :--- |
| **কর্তৃকারক** | কে / কারা ক্রিয়া সম্পাদন করছে? | **পাগলে** কিনা বলে (কর্তায় ৭মী) |
| **কর্মকারক** | কাকে / কী করছে? | **ডাক্তার** ডাকো (কর্মে শূন্য) |
| **করণকারক** | কীসের দ্বারা / কী উপায়ে হচ্ছে? (Instrument) | **কলমে** ভালো লেখা হয় (করণে ৭মী) |
| **সম্প্রদান কারক** | নিঃস্বার্থভাবে চিরতরে দান করা বোঝালে। | **ভিখারীকে** ভিক্ষা দাও (সম্প্রদানে ৪থী) |
| **অপাদান কারক** | যা থেকে কিছু বিচ্যুত, জাত, ভীত, আরম্ভ বা পতিত হয়। | **তিলে** তৈল হয় (অপাদানে ৭মী), **মেঘে** বৃষ্টি হয় |
| **অধিকরণ কারক** | ক্রিয়া সম্পাদনের স্থান, কাল বা বিষয় বোঝালে। | **তিলে** তৈল আছে (অধিকরণে ৭মী — তিলের সর্বাঙ্গে বিদ্যমান) |

> [!TIP]
> *"তিলে তৈল হয়"* ➔ তেল নিষ্কাশিত/উৎপন্ন হচ্ছে বলে **অপাদান কারক**।
> *"তিলে তৈল আছে"* ➔ তিলের ভেতরে স্থান জুড়ে অবস্থান করছে বলে **অধিকরণ কারক**।

## 📌 ৪. বাক্য শুদ্ধি ও প্রচলিত অপপ্রয়োগ (Mistakes to Avoid)

1. **বহুবচনের দ্বিত্ব প্রয়োগ ভুল:**
   * অশুদ্ধ: *সকল মেম্বারগণ উপস্থিত ছিলেন।*
   * শুদ্ধ: **সকল মেম্বার** উপস্থিত ছিলেন। (বা: **মেম্বারগণ** উপস্থিত ছিলেন)।
2. **প্রত্যয়জনিত ভুল:**
   * অশুদ্ধ: *তার দারিদ্র্যতা দেখে কষ্ট পেলাম।*
   * শুদ্ধ: তার **দরিদ্রতা** (বা **দারিদ্র্য**) দেখে কষ্ট পেলাম।
   * অশুদ্ধ: *তিনি আরোগ্য হয়েছেন।* ➔ শুদ্ধ: তিনি **আরোগ্য লাভ** করেছেন।
3. **বানানজনিত অপপ্রয়োগ:**
   * অশুদ্ধ: *ইতিপূর্বে* ➔ শুদ্ধ: **ইতোপূর্বে**।
   * অশুদ্ধ: *উপরোক্ত* ➔ শুদ্ধ: **উপরি-উক্ত** (বা উপযুক্ত)।
   * অশুদ্ধ: *শশীভূষণ* ➔ শুদ্ধ: **শশিভূষণ** (সন্ধিতে ঈ-কার হ্রস্ব-ই হয়)।
   * অশুদ্ধ: *নিরপরাধী ব্যক্তি* ➔ শুদ্ধ: **নিরপরাধ** ব্যক্তি।

## 📌 ৫. বাংলা সাহিত্যের শীর্ষ মাইলফলক ও তথ্যকোষ

* **বাংলা ভাষার আদি নিদর্শন:** **চর্যাপদ** (আবিষ্কারক: মহামহোপাধ্যায় হরপ্রসাদ শাস্ত্রী, ১৯০৭ সালে নেপালের রাজদরবারের রয়েল লাইব্রেরি থেকে)। মোট পদ সংখ্যা সাড়ে ৪৬টি (২৩ জন পদকর্তা, সর্বাধিক পদ রচয়িতা **কাহ্নপা** - ১৩টি)।
* **মধ্যযুগের প্রথম কাব্য:** বড়ু চণ্ডীদাস রচিত **শ্রীকৃষ্ণকীর্তন** (১৯০৯ সালে বসন্তরঞ্জন রায় বিদ্বদ্বল্লভ বাঁকুড়ার এক গোয়ালঘর থেকে উদ্ধার করেন)।
* **মঙ্গলকাব্যের শ্রেষ্ঠ কবি:** অন্নদামঙ্গল কাব্যের কবি **ভারতচন্দ্র রায়গুণাকর**।
* **বাংলা সাহিত্যের প্রথম সনেট ও মহাকাব্য:** মাইকেল মধুসূদন দত্ত (প্রথম সনেট: 'বঙ্গভাষা', প্রথম সার্থক মহাকাব্য: ১৮৬১ সালের 'মেঘনাদবধ কাব্য')।
* **রবীন্দ্রনাথ ঠাকুর:** ১৯১৩ সালে 'গীতাঞ্জলি' কাব্যের ইংরেজি অনুবাদের জন্য এশিয়ার মধ্যে প্রথম সাহিত্যে নোবেল পুরস্কার পান।
* **কাজী নজরুল ইসলাম:** জাতীয় কবি, প্রথম প্রকাশিত কবিতা 'মুক্তি' (১৯১৯), প্রথম কাব্যগ্রন্থ 'অগ্নি-বীণা' (১৯২২)।
* **মুক্তিযুদ্ধভিত্তিক শীর্ষ উপন্যাস:**
  * 'রাইফেল রোটি আওরাত' — আনোয়ার পাশা (মুক্তিযুদ্ধের প্রথম উপন্যাস)।
  * 'হাঙর নদী গ্রেনেড' — সেলিনা হোসেন।
  * 'আগুনের পরশমণি' ও 'শ্যামল ছায়া' — হুমায়ূন আহমেদ।
  * 'একাত্তরের দিনগুলি' — জাহানারা ইমাম (স্মৃতিকথা)।
