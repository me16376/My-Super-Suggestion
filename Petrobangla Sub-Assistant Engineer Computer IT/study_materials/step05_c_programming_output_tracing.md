# 🇧🇩 পেট্রোবাংলা উপ-সহকারী প্রকৌশলী (কম্পিউটার/আইটি) লিখিত প্রস্তুতি
## ধাপ ৫: সি প্রোগ্রামিং (C Programming) — Output Tracing ও মেমরি হ্যান্ডলিং গাইড

> **বুয়েট (BUET) ফোকাস বিশ্লেষণ:** বুয়েট কর্তৃক গৃহীত পাওয়ার ও গ্যাস সেক্টরের (তিতাস, বাখরাবাদ, ডেসকো, ডিপিডিসি, পিজিসিবি) উপ-সহকারী প্রকৌশলী লিখিত পরীক্ষায় সি প্রোগ্রামিং থেকে প্রতিবারই ৮ থেকে ১০ নম্বরের **আউটপুট ট্রেসিং (Output Tracing)** সমস্যা আসে। এখানে থিওরি জানতে চাওয়া হয় না; সরাসরি কোড দিয়ে স্টেপ-বাই-স্টেপ মেমরি বিশ্লেষণ করে আউটপুট লিখতে বলা হয়।

## 📌 ১. পয়েন্টার ও ইনক্রিমেন্ট-ডিক্রিমেন্ট অপারেটরের গোল্ডেন রুলস

বুয়েটের পরীক্ষায় সবচেয়ে বেশি আসা ট্রিকি প্রশ্নগুলোর একটি হলো `*ptr++`, `*++ptr`, `++*ptr` এবং `(*ptr)++` এর পার্থক্য:

```c
int arr[] = {10, 20, 30, 40};
int *ptr = arr; // ptr পয়েন্ট করছে arr[0] (10) কে
```

| এক্সপ্রেশন | কী ঘটে (স্টেপ বাই স্টেপ) | ফলাফল / মান | পয়েন্টারের বর্তমান অবস্থান |
| :--- | :--- | :---: | :---: |
| `*ptr++` | পোস্ট-ফিক্স `++` পরে কাজ করে। বর্তমান অ্যাড্রেসের মান রিটার্ন করে, তারপর পয়েন্টার ১ ঘর সামনে যায়। | **১০** | `arr[1]` (২০) |
| `*++ptr` | প্রি-ফিক্স `++` আগে পয়েন্টারকে ১ ঘর সামনে নেয়, তারপর নতুন অ্যাড্রেসের মান রিটার্ন করে। | **২০** | `arr[1]` (২০) |
| `++*ptr` | পয়েন্টার সরে না। পয়েন্টার যেখানে নির্দেশ করছে সেই মেমরির মূল মানের সাথে সরাসরি ১ যোগ করে। | **১১** | `arr[0]` (১১) |
| `(*ptr)++` | পয়েন্টার সরে না। বর্তমান মান রিটার্ন করে, তারপর সেই মেমরির মূল মানকে ১ বৃদ্ধি করে। | **১০** (পরে ১১ হয়) | `arr[0]` (১১) |

> [!IMPORTANT]
> **প্রেসিডেন্স নিয়ম:** পোস্টফিক্স অপারেটর `++` এবং ডি-রেফারেন্স অপারেটর `*` এর মধ্যে `++` এর প্রেসিডেন্স বেশি। কিন্তু এটি পোস্টফিক্স হওয়ায় এক্সপ্রেশন মূল্যায়নের পরে ইনক্রিমেন্ট কার্যকর হয়। ব্র্যাকেট `(*ptr)++` দিলে ভেতরের পয়েন্টার ডি-রেফারেন্স আগে ঘটে এবং মানের ওপর ইনক্রিমেন্ট প্রয়োগ হয়।

## 📌 ২. ডাবল পয়েন্টার (Double Pointer `**ptr`) দিয়ে অ্যাড্রেস রি-ডিরেকশন

ফাংশনে সাধারণ পয়েন্টার পাস করলে পয়েন্টারটি নিজে কল-বাই-ভ্যালু (Call-by-value) হিসেবে কপি হয়। কলার ফাংশনের মূল পয়েন্টারের অ্যাড্রেস পরিবর্তন করতে হলে অবশ্যই **ডাবল পয়েন্টার** ব্যবহার করতে হয়।

### কোড ট্র্যাকিং উদাহরণ:
```c
#include <stdio.h>
void change(int **ptr, int *target) {
    *ptr = target; // মূল পয়েন্টার p এর ভেতরের অ্যাড্রেস বদলে দেওয়া হলো
}
int main() {
    int x = 50, y = 100;
    int *p = &x;
    change(&p, &y);
    printf("*p = %d, x = %d, y = %d\n", *p, x, y);
    return 0;
}
```
* **আউটপুট:** `*p = 100, x = 50, y = 100`
* **ব্যাখ্যা:** `change()` ফাংশনে `p`-এর নিজস্ব মেমরি অ্যাড্রেস পাঠানো হয়েছিল। `*ptr = target;` করায় `main()` ফাংশনের `p` এখন সরাসরি `y`-কে পয়েন্ট করছে।

## 📌 ৩. স্ট্রাকচার মেমরি প্যাডিং ও অ্যালাইনমেন্ট (Structure Padding)

৩২-বিট বা ৬৪-বিট প্রসেসর বাস সাইকেল সাশ্রয় করতে মেমরিকে ৪-বাইট বা ৮-বাইটের ওয়ার্ড বাউন্ডারিতে সাজায়। এর ফলে স্ট্রাকচারের আকারের সাথে অপ্রত্যাশিত অতিরিক্ত বাইট (Padding) যোগ হয়।

```c
struct Demo {
    char a;    // 1 byte
    // + 3 bytes padding (int এর 4-বাইট বাউন্ডারির জন্য)
    int b;     // 4 bytes
    char c;    // 1 byte
    // + 3 bytes padding (মোট আকার 4 এর গুণিতক করার জন্য)
};
```
* **সাধারণ যোগফল:** 1 + 4 + 1 = 6 বাইট।
* **প্রকৃত `sizeof(struct Demo)`:** **12 বাইট!**

### প্যাডিং বন্ধ করার কৌশল (`#pragma pack`):
```c
#pragma pack(1) // ১ বাইট অ্যালাইনমেন্ট নিশ্চিত করে
struct PackedDemo {
    char a;    // 1 byte
    int b;     // 4 bytes
    char c;    // 1 byte
};
#pragma pack()
```
* **এখন `sizeof(struct PackedDemo)`:** **6 বাইট** (কোনো প্যাডিং নেই)।

## 📌 ৪. বিটওয়াইজ ট্রিকস ও ব্রায়ান কার্নিঘান অ্যালগরিদম

বুয়েটে বিটওয়াইজ অ্যান্ড (`&`), অর (`|`), এক্সঅর (`^`) ও শিফট (`<<`, `>>`) প্রচুর আসে:

### ১. পাওয়ার অফ টু (Power of 2) যাচাই:
```c
if ((n > 0) && ((n & (n - 1)) == 0)) {
    printf("Number is a Power of 2\n");
}
```
* **লজিক:** ২-এর পাওয়ারের বাইনারিতে মাত্র একটি '1' থাকে (যেমন: 8 = 1000)। 8 - 1 = 7 (0111)। এদের AND করলে `1000 & 0111 = 0000` হয়!

### ২. সেট বিট কাউন্ট (Brian Kernighan's Algorithm):
```c
int countSetBits(int n) {
    int count = 0;
    while (n > 0) {
        n = n & (n - 1); // প্রতি ধাপে সর্বডানের '1' মুছে যায়
        count++;
    }
    return count;
}
```

## 📌 ৫. ম্যাক্রো এক্সপ্যানশন ট্র্যাপ (Macro Trap)

```c
#define SQUARE(x) x * x
int result = SQUARE(3 + 2);
```
* **ভুল ধারণা:** (3 + 2)^2 = 25।
* **আসল হিসাব:** প্রি-প্রসেসর সরাসরি টেক্সট বসায়: `3 + 2 * 3 + 2` = `3 + 6 + 2` = **11**!
* **সমাধান:** `#define SQUARE(x) ((x) * (x))` ব্যবহার করতে হয়।

## 📌 ৬. রিকার্শন কল স্ট্যাক ও আনওয়াইন্ডিং (Recursion Tracing)

```c
void count(int n) {
    if (n <= 0) return;
    printf("%d ", n);   // ফরওয়ার্ড প্রিন্ট
    count(n - 1);       // রিকার্সিভ কল
    printf("%d ", n);   // আনওয়াইন্ডিং প্রিন্ট (রিভার্স)
}
// count(3) কল করলে আউটপুট: 3 2 1 1 2 3
```

> [!TIP]
> রিকার্সিভ কলের আগের কোড **টপ-টু-বটম (3, 2, 1)** এক্সিকিউট হয়, এবং রিকার্সিভ কলের পরের কোড স্ট্যাক থেকে পপ হওয়ার সময় **বটম-টু-টপ (1, 2, 3)** এক্সিকিউট হয়।
